CI 會驗證套件安裝、物理小案例、資料儲存與讀回，以及文件。這些測試使用明確宣告的小型案例。

## 主題

- [CI 與 Pages](ci.md)：工作流程何時執行、變更如何分類、產品工作與版本化文件發布。
- [電路輸入與元件](circuit-data.md)：RLGC 資料、Q2D 載入、元件工廠與電感耦合。
- [網路方程式與根](network-roots.md)：Direct 物理量、導納、導數，以及極點或零點證書。
- [參數與最佳化](parameters-optimization.md)：仿射授權、區域座標尺度與最佳化案例。
- [證據與讀回](evidence-readback.md)：v3 成品，以及 Memory／Workspace 解析。
- [錯誤處理與診斷](diagnostics.md)：原生錯誤路由與求解診斷。
- [路徑、電路圖與教材輸出](portability-diagrams.md)：路徑可攜性、手繪電路圖、筆記本與課程輔助程式。
- [數值檢查與本機執行](numerical-checks.md)：比較界限與本機 unittest 指令。
